  `logit(0.523) - logit(0.731) = -0.91` и `logit(0.930) - logit(0.878) = +0.61`.

  отклонена, см. `superseded/README_RU.md`). Порядок внутри класса сохраняется.
  Затронуто 5 657 клеток. Проверено: строгих инверсий порядка 0, в потолок 0.99 не упёрлась

## 5. Гейт

Запускать `artifacts/severity_labels_probe_v1/gate_severity.py`:

```
python3 gate_severity.py --baseline <база>/averaged_predictions.csv --arm <арм>/averaged_predictions.csv
```

**Ловушка, которую нельзя пропустить.** `RESULT.json` арма считает pseudo AUC против
СОБСТВЕННЫХ (изменённых) меток — с базой он несравним. Сравнение делается только скриптом
выше и только против исходного `folds_core5_v1.csv`.

Главная метрика — **`untouched_macro`**: позитивы = отчётные позитивы БЕЗ слова степени,
негативы = явные негативы отчёта. Цели этих клеток одинаковы в базе и в обоих армах, поэтому
разница не может быть механическим следствием сдвига целей. База (fold 3):

| метрика | база |
|---|---|
| `untouched_macro` | **0.9068** |
| `pseudo_macro` | 0.9095 |
| `mild_macro` | 0.8781 |
| `high_macro` | 0.9524 |
| `untouched_obl20` | 0.8654 |

**Правило решения, зафиксировано заранее:**
- PASS → full-fit и LB, если `untouched_macro` ≥ **+0.004** с нижней границей CI95 > 0
  (кластерный бутстрап по `report_group`, 2000 драв), И `pseudo_macro` упал не более чем на
  0.010, И `untouched_obl20` не хуже базы более чем на 0.005.
- Падение `pseudo_macro` на 0.002–0.008 ожидаемо и само по себе не FAIL: метка изменена намеренно.
- FAIL → ветка закрывается, результат записывается, второй заход по той же оси не делается.
- Если проходят оба арма — в full-fit идёт один, с бо́льшим `untouched_macro`.
- Описательно, без права решать: Gold58 macro (база AUX60 fold 3 = 0.9265), `mild_macro`,
  `high_macro` (ожидание: разрыв high − mild растёт), per-target Effusion и PF OA.
